# Task-4 Visualization

## Objective

The objective of this project is to analyze the cleaned dataset using data visualization techniques and generate meaningful business insights through charts, graphs, and dashboard-style analysis.

## Tasks Performed
- Created monthly sales trend analysis
- Analyzed top-selling products
- Visualized payment method distribution
- Performed city-wise revenue analysis
- Created order status distribution charts
- Generated correlation heatmap
- Calculated important KPIs

## Key Insights
- Sales varied across different months.
- Some products generated higher revenue compared to others.
- Digital payment methods were most preferred by customers.
- Certain cities contributed significantly to total sales.
- Positive correlation existed between Quantity and TotalPrice.
