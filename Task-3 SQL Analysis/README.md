# Task-3 SQL Analysis

## Objective
The objective of this task is to perform SQL-based data analysis on a cleaned e-commerce dataset using SQL queries in Google Colab with SQLite.
The project focuses on extracting meaningful business insights using:
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()

## Steps Performed
1.-Uploaded cleaned Excel dataset in Google Colab
2.-Imported required libraries
3.-Loaded dataset using Pandas
4.-Created SQLite database connection
5.-Converted dataset into SQL table
6.-Executed SQL queries for analysis
7.-Generated insights from query outputs
