# Task-3 SQL Analysis

## Objective
The objective of this task is to perform SQL-based data analysis on a cleaned e-commerce dataset using SQL queries in Google Colab with SQLite.
The project focuses on extracting meaningful business insights using:
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()

## Steps Performed
- Uploaded cleaned Excel dataset in Google Colab
- Imported required libraries
- Loaded dataset using Pandas
- Created SQLite database connection
- Converted dataset into SQL table
- Executed SQL queries for analysis
- Generated insights from query outputs
